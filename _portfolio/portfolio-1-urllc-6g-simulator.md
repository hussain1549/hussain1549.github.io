Developed a Python and MATLAB simulation framework for ultra-reliable low-latency communication in 6G edge networks. The framework integrates realistic channel models, traffic patterns, and queueing delays.

I implemented and evaluated reinforcement-learning based resource allocation and routing schemes that aim to meet strict latency and reliability targets under interference and traffic fluctuations.

**Tools:** Python, MATLAB
