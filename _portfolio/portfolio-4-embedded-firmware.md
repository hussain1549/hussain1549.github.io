Developed C and C++ firmware for a real-time sensor acquisition system with kHz-level sampling, implementing communication protocols, buffering, and low-latency data transfer on microcontroller and embedded Linux platforms.

I optimised memory and timing to guarantee deterministic behaviour, and built Python tools for monitoring, analysis, and automated test campaigns.

**Tools:** C, C++, Embedded Linux, Python
